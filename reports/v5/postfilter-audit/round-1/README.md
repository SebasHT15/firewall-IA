## Steps to the per-category acceptance report

1. **Owner:** choose the two annotator models. They must differ (D58). Proposal: a1 = Claude Sonnet, a2 = another
   model you name. The coordinator never annotates.
2. **Coordinator:** write `annotators.json`:

   ```
   {"a1": {"model": "...", "agent": "read-only subagent", "date": "..."}, "a2": {"model": "...", ...}}
   ```

   Then run each annotator as a separate read-only session, given only its own `annotation_aN/` folder. Each writes
   `annotations_aN.jsonl`. They never see each other's output or the human files.
3. **Human reviewer (owner or a delegate):** do the blind review in `human_review/` (see its README). It can run in
   parallel with step 2, because it never reads LLM output.
4. **Coordinator:** run `python3 scripts/dataset/audit_v5_postfilter.py adjudication-sheet --round 1`. It lists the
   disagreements that need a decision; V/P splits resolve to P by rule.
5. **Coordinator or owner:** write `adjudication.jsonl`, one row per listed item:

   ```
   {"sample_id", "label_class", "failure_mode", "adjudicator", "adjudicator_role": "coordinator"|"owner", "rationale"}
   ```

   Agreed labels cannot be overridden.
6. **Anyone:** run `python3 scripts/dataset/audit_v5_postfilter.py report --round 1`. It writes `report.json` and
   `report.md` with a status per category: PENDING_* until the inputs are complete, then PASS or FAIL.
7. **Owner:** sign off the report.
   - A **FAIL** category is excluded from V5 TRAIN, or re-audited once (round 2) after a documented filter change, with
     a new seed and only for the failed categories.
   - A **PASS** makes a category eligible. Marking its payloads VERIFIED is a separate owner decision.

**Never:** invented labels, simulated human review, LLM agreement presented as human validation, a redraw of round 1,
or relaxing a threshold after seeing results (C-R6).
